# TP2: Financial Account Dashboard 💰

**Course:** Data Visualization and SQL  
**Institution:** Infnet Institute  
**Tool:** Looker Studio (Google)

## 🎯 Objective
Develop an interactive financial report ("Consolidação do Contador") to visualize transaction data, focusing on balance metrics and time-series analysis.

## 🛠 Features Implemented
* **Data Integration:** Connected Google Sheets to Looker Studio.
* **Branding:** Custom header with "Chris Cooper" branding.
* **Key Metrics (Scorecards):**
    * Average Balance
    * Maximum Balance
    * Minimum Balance
* **Visualizations:**
    * Time Series Chart (Avg Balance over time)
    * Detailed Transaction Table (Date, Description, Memo, Account, Balance)
* **Interactivity:** Date Range Control filter.
