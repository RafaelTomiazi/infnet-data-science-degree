# Final Assessment: Financial Dashboard & SQL 📊

**Course:** Data Visualization and SQL  
**Institution:** Infnet Institute  
**Type:** Final Project (AT)

## 🎯 Overview
This assessment is divided into two major parts:
1.  **Financial Dashboard:** An interactive report created in Looker Studio to analyze bank account transactions (Checking Account).
2.  **SQL Database Analysis:** A comprehensive set of 20 SQL queries performed on a Customer Database (`Cliente` table) using Deepnote.

---

##  PART 1: Looker Studio Dashboard 🏦
**Project:** "Conta Corrente - Consolidação do Contador"

### Features
* **Data Source:** [`financial_transactions.csv`](./financial_transactions.csv) (Original dataset)
* **Scorecards:** Average, Max, and Min Balance (2017 vs 2018).
* **Time Series:** Balance evolution comparison.
* **Tables:** Monthly breakdown of transactions.
