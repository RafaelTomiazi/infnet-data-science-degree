# TP3: SQL Operators & Filtering 🔍

**Course:** Data Visualization and SQL  
**Institution:** Infnet Institute  
**Tool:** Deepnote (Python/SQL integration)

## 🎯 Objective
Master the usage of SQL filtering operators (`WHERE`, `AND`, `OR`, `BETWEEN`, `IN`) to query a dataset of Actors and Actresses.

## 📂 Project Structure
* **[`queries.sql`](./queries.sql):** Contains the complete SQL script with the Table Creation and solutions for Bronze, Silver, and Gold challenges.
* **[`rafael_tomiazi_DR1_TP3.pdf`](./rafael_tomiazi_DR1_TP3.pdf):** Evidence of code execution and results from Deepnote.

## 🚀 Key Concepts Demonstrated
* **Comparison Operators:** `>`, `<`, `=`, `!=`, `>=`, `<=`
* **Logical Operators:** `AND`, `OR`
* **Range & List Filtering:** `BETWEEN`, `NOT BETWEEN`, `IN`, `NOT IN`
