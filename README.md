## 📁 How this repository is organized

```
semester-XX/
  <course>/
    README.md        course overview: syllabus, deliverables, notes index
    notes/           class notes, one file per class (YYYY-MM-DD-topic.md)
    exercises/       in-class and practice exercises
    assessments/     graded work: tp1-..., tp2-..., tp3-..., at-...
    datasets/        small public datasets used in the course
templates/           templates for class notes, course README and assessments
```

Class notes are written in Portuguese; assessment READMEs are in English.
